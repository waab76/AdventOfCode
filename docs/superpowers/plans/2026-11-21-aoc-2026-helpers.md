**Goal:** Create `2026/common.py` with 2025's helpers plus a few new grid/parsing/search helpers.

**Architecture:** One flat module of plain, type-hinted functions and constants, matching `2025/common.py`. Tests live in a scratch script outside the repo (per spec, not committed).

**Tech Stack:** Python 3 standard library only (`re`, `heapq`, `collections.deque`).

**Spec:** `docs/superpowers/specs/2026-11-21-aoc-2026-helpers-design.md`

## Global Constraints

- Standard library only; no third-party imports.
- Existing 2025 helper names, signatures and behavior unchanged.
- Do not modify prior years' files.
- Test script lives at `$SCRATCH/test_common.py` (scratchpad: `/private/tmp/claude-501/-Users-rcurtis-Workspace-AdventOfCode/a53b97a0-bba6-47ee-8abe-817051e7c615/scratchpad`), run with `python3 $SCRATCH/test_common.py` from the repo root; it does `sys.path.insert(0, '2026')` then `from common import *`.

## Review Focus

- `ints` on `"x=-3, y=10"` must return `[-3, 10]`; a hyphen between words/numbers like `"1-2"` → `[1, -2]` is accepted (standard AoC behavior), but `"abc"` → `[]`.
- `neighbors` at grid corners must not yield negative indices (Python wrap-around would silently succeed).
- `in_bounds` with ragged grids: checks against `len(grid[row])`, not `len(grid[0])`.
- `dijkstra` must handle a state reached first by a costlier path and later by a cheaper one (stale heap entries skipped).
- `bfs`/`dijkstra` states may be any hashable (tuples incl. direction), and states must not be compared directly in the heap when costs tie (use a counter tiebreaker).

def test_task2():
    g = [list("..#"), list(".#."), list("...")]
    open_nb = lambda p: [q for q in neighbors(g, *p) if g[q[0]][q[1]] == '.']
    d = bfs((0, 0), open_nb)
    assert d[(0, 0)] == 0 and d[(2, 2)] == 4 and (0, 2) not in d
    edges = {'A': [('B', 5), ('C', 1)], 'C': [('B', 1)], 'B': []}
    assert dijkstra('A', lambda s: edges[s]) == {'A': 0, 'C': 1, 'B': 2}
    # tied costs with non-comparable-ish states must not raise
    tie = {(0, 'x'): [((1, 'y'), 1), ((1, None), 1)], (1, 'y'): [], (1, None): []}
    assert dijkstra((0, 'x'), lambda s: tie[s])[(1, None)] == 1
